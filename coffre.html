Le coffre de Varenne

ÉPREUVE MÉCANIQUE · PROTOTYPE V8

« Faites tourner la roue vers la droite. Les chiffres suivent le cadran, dans les deux sens. Écoutez ses crans : l’un d’eux sonnera différemment. Lorsque vous pensez reconnaître le bon cran, repartez en sens inverse : le chiffre que vous avez choisi sera conservé, même s’il est faux. Continuez ainsi pour les cinq chiffres. Après le cinquième, appuyez sur le grand bouton pour tenter d’ouvrir mon coffre. Attention : vous pouvez dépasser le bon cran ! » — Émile Varenne

CHIFFRES DU CADRAN · DROITE / GAUCHE

Le bouton sera disponible après les cinq mouvements.

Les chiffres gravés autour du cadran restent fixes (1 à 9). Le chiffre sous le triangle est celui enregistré dans la colonne active. À chaque inversion, le chiffre précédent est conservé, même faux. Faites tourner la roue intérieure avec le doigt, lentement. Une vibration marque chaque cran ; un clic plus net se fait sentir au bon cran. La roue ne s’arrête jamais : c’est à vous de choisir quand inverser le sens. Après le cinquième mouvement, appuyez sur le grand bouton doré pour tenter l’ouverture.
